# PaperMarket 시험 이용약관 초안

버전: `terms-trial-v6` / 개발 안내 기준일: 2026-10-09. 운영 주체와 실제 적용일은 공개 전 확정합니다. 실행 중 `/help`는 실제 운영 주체·지원 연락처를 표시합니다. [이전 v5](versions/TERMS_TRIAL_V5.md)와 v4·v3·v2·v1 원본을 보관합니다. 이 문서는 법률 자문이 아닌 개발용 초안이며 실사용자 데이터나 결제를 받기 전 운영 사실을 확정하고 전문가 검토를 받아야 합니다.

## 서비스와 시험 범위

PaperMarket은 가상 기업의 자산으로 투자 판단을 세우고 결과를 추적하는 모의투자 시뮬레이터입니다. 기업·현금·주식·거래는 모두 가상입니다. 실제 금융계좌·결제·환전·상품 판매·현금 보상은 제공하지 않습니다. 가상자금·계좌를 구매하거나 판매·양도할 수 없습니다. 다른 참가자가 없어도 본인 계좌를 개설하고 시스템에 시장가 매수·매도를 요청할 수 있습니다.

단계 5는 기업 회계·부채·가상 금리·공개 전망·사건 콘텐츠와 배당·부실·청산에 기업 상세·일정·뉴스·차트·성과·기준전략·개인 알림·내보내기를 더합니다. 사건은 실제 뉴스가 아닌 가상 기업의 시나리오입니다. 공개 시차·실제/예상/이전 값·불확실성을 구분하고 미공개 결과를 공개 시세 근거로 사용하지 않습니다. 사용자 수·주문량·조회·알림 발송은 가격 경로를 바꾸지 않으며 전망은 확정 결과가 아닙니다. 현금 이자는 가상 연 252틱의 이율과 구간별 활성 보유시간으로 계산해 틱말에 지급합니다. 시험 결과는 실제 투자 수익을 예측하거나 보장하지 않습니다.

배당은 선언 T, 권리 확정 T+3, 지급 예정 T+5의 경제 틱을 기준으로 처리합니다. 권리 확정 직전 보유 수량으로 결정되고 이후 매도해도 유지되며 늦게 매수하면 해당 권리를 얻지 못합니다. 명목 금액·현재 평가·실제 지급은 다르고 기업 손상·청산으로 지급이 줄거나 0이 될 수 있습니다. 배당락과 권리 분리·현금 지급은 순자산에 중복 합산하지 않습니다.

청산 종목은 거래를 중단하고 기존 수량·취득원가를 회수권으로 이전합니다. 비용과 채권자 우선순위 뒤 남은 재산으로 최종 회수하며 손실은 그대로 남습니다. 같은 슬롯에 새 회사가 상장돼도 다른 발행사·종목이므로 새 주식이나 보상 현금을 자동으로 지급하지 않습니다.

## 계좌 개설과 이용

만 14세 이상 이용자가 개설할 수 있습니다. 이용자는 `/help`와 `/privacy`를 확인하고 `/open`에서 만 14세 이상과 이용약관 동의를 각각 명시적으로 선택합니다. 기본적으로 선택되었다고 간주하지 않으며 생년월일을 받지 않습니다. 연령은 이용자의 자기 확인이며 신분 검증은 제공하지 않습니다. 개인정보 처리 목적과 저장 사항은 별도의 개인정보 처리 안내에서 설명합니다.

계좌는 시장과 Discord 사용자에 연결됩니다. 최초자금 10,000은 시장별 한 번만 지급됩니다. 이름 변경, 서버 탈퇴 후 재가입, 봇 재초대, 계좌 종료로 재지급되지 않습니다. Discord 계정·접근 권한은 안전하게 관리해야 하며 타인 계정·주문을 사용하거나 소유자 확인·명령 제한을 우회하면 안 됩니다.

## 주문과 결과 확인

시장가 주문의 수량 또는 예산을 입력하면 시스템이 시세·수량·거래대금·수수료·체결 후 현금·유효기간을 표시합니다. 이용자가 확인 버튼을 누르고 소유자·유효기간·확정 시세 버전·자산 조건을 충족하면 전량 체결합니다. 확인 전 요청·취소·만료·거절은 체결이 아닙니다. 같은 확인을 다시 누르면 기존 결과를 제공하여 이중 체결을 막습니다.

지정가 매수·매도와 스톱 매도는 수량·조건가격·유효기간을 입력합니다. 스톱은 매도만 지원하며 지정가·스톱에 예산·전량 옵션을 함께 사용하지 않습니다. 확인 토큰은 최대 30초이고 견적 단계에는 자산을 예약하지 않습니다. 확인 시 이미 조건을 충족하면 현재 확정가로 체결하고 그 외에는 새 확정 시세마다 평가합니다. 지정가 매수는 현재가가 조건가격 이하, 지정가 매도는 이상, 스톱 매도는 이하일 때 실제 현재가로 전량 체결합니다. 스톱은 950에서 800으로 갭 하락해 900 조건을 통과했다면 800에 체결될 수 있으며 손실액을 보장하지 않습니다.

지정가 매수는 수량×조건가격과 최대 수수료에 해당하는 현금을, 매도·스톱은 주식 수량을 예약합니다. 예약 현금은 총 현금에 포함되고 예치이자를 얻으며 예약 주식도 배당 권리를 유지합니다. 중복 예약을 허용하지 않습니다. 기본 유효기간은 전체 시장 21틱이고 1~10,000틱 또는 취소할 때까지를 선택합니다. 정확히 만료 틱에서는 체결하지 않으며 같은 계좌의 여러 조건주문은 접수 순번으로 평가합니다. 경계에서는 만료→기업행동 취소→새 시세→조건 평가 순서로 처리합니다. 배당락·교환·소멸 때 해당 종목의 미체결 주문은 취소하고 새 종목으로 자동 이전하지 않습니다. 단순 배당 지급일은 취소 사유가 아닙니다.

본인 모의자산·가용/예약 자산·배당 및 청산 권리는 `/portfolio`, 체결·배당·정정 이력은 `/history`, 조건주문과 취소는 `/orders`에서 비공개로 확인합니다. 공개 지표·기업행동·사건 공시는 `/economy`, 공개 실적은 `/financial`, 기업 상세·일정·뉴스는 `/company`·`/calendar`·`/news`에서 확인합니다. 공개 현황판에는 개인 거래를 표시하지 않습니다. 시세·계좌가 바뀌어 견적이 무효화되면 새 견적과 명시적인 재확인이 필요합니다.

## 차트·성과·기준전략

`/chart`는 서버에 확정 저장된 틱말 가격 또는 총수익 자료로 정적 이미지를 만듭니다. 실제 시간·가상 틱·배당락·종목 세대를 표시하고 실제로 관측하지 않은 틱 내 고가·저가를 만들지 않습니다. 로그 차트에서는 0을 유효한 로그 가격으로 바꾸지 않습니다. 차트 생성 실패는 조회 실패로 안내하며 금융 기록을 다시 실행하지 않습니다. 화면의 시세 버전·갱신 시각·정지 상태를 확인해야 합니다.

`/performance`의 순자산은 총 현금·보유 주식 평가·회수권 평가·발생 이자를 한 번씩 포함합니다. 배당 지급과 예약 현금을 중복으로 더하지 않습니다. 수익률은 최초자금 10,000 대비이며 최대 낙폭은 저장된 틱말 표본과 현재 조회 시점으로 계산합니다. 샘플 밖의 순간 손실까지 측정한 값이 아닙니다. 수수료는 손익에 이미 반영된 비용으로 별도 표시하며 다시 차감하지 않습니다.

CASH는 계좌 개설 시점의 동일 최초자금으로 현금만 보유하고, HOLD8은 당시 8종목을 비용을 지불해 동일 금액으로 산 뒤 보유합니다. 배당·이자·청산 권리와 손실을 유지하고 새 회사 주식을 무상으로 받지 않습니다. 이전 버전 계좌의 최초 부분 구간에서 활성 보유시간을 정확히 복원할 수 없으면 `LEGACY_BOUNDARY_ONLY`로 표시하고 그 구간의 기준전략 이자를 보수적으로 제외합니다. 과거 이자를 정확히 재현했다는 의미가 아닙니다.

PM8은 단계 5 도입 때 공개된 확정 시세에서 시작하는 시장 기준이며 과거 성과를 소급해 만들어내지 않습니다. 21틱마다 활성 8종목에 동일 금액으로 재배분하며 거래 비용을 지불합니다. 현금화되지 않은 청산 권리를 구매 예산으로 쓰거나 기존 손실을 초기화하지 않습니다. 기준전략은 사용자 계좌에 보상·자산을 지급하거나 투자 행동을 추천하지 않습니다.

## 개인 알림과 내보내기

`/alerts`의 본인 알림함은 중요한 공개 공시·배당 권리·지급·조건주문 체결/취소·등록한 가격 조건을 보관하며 최근 1,000건을 유지합니다. 관심종목과 가격 조건은 각각 최대 20개입니다. 종목의 영구 상장 ID에 연결하므로 종목 소멸 때 비활성화하고 후속 회사로 이전하지 않습니다. 가격 조건은 해당 방향을 통과하면 한 번 알리고 반대편으로 돌아온 뒤에 다시 준비합니다.

DM은 기본 꺼짐이며 `/alerts dm:true`로 별도 선택할 때만 켭니다. 목적은 개인 알림 전달이고, 필요한 사용자 ID·확정 알림 내용이 Discord에 전달됩니다. 거부해도 계좌·거래·비공개 알림함을 사용할 수 있습니다. 같은 설정에서 `dm:false`로 철회하면 대기 발송을 취소하며 이미 보낸 메시지는 회수하지 않습니다. 원래 주문 Interaction 토큰으로 지연 알림을 보내지 않습니다.

알림은 금융 기록과 함께 준비되고 발송은 커밋 이후 별도로 재시도합니다. 발송 실패가 체결을 취소하거나 이중 실행하지 않습니다. Discord 장애·수신 차단·발송 후 확인 전 중단으로 지연·누락·중복이 생길 수 있으므로 외부 발송의 정확히 한 번 전달을 보장하지 않습니다. 본인 `/orders`·`/history`·`/alerts`에서 확정 기록을 확인합니다.

`/export`는 본인 계좌 기록을 CSV·JSON 첨부로 생성해 비공개 응답에 전달합니다. 한 번에 최대 1,000개 이력 항목과 다음 페이지 기준을 제공하므로 전체 이력은 페이지를 이어 받아야 합니다. CSV는 계좌·이력·보유·권리·성과·체결 비용·설정/동의·최근 알림을 8개 파일로 제공하며 전체 첨부는 2MB 이내로 제한합니다. 파일은 봇 디스크에 보관하지 않으며 운영 시드·미공개 기업 상태·확인 nonce·다른 계좌를 포함하지 않습니다. CSV는 수식 실행 문자를 이스케이프합니다. 첨부 파일이 전달된 후 Discord 자체 보관과 이용자가 내려받은 사본은 별도입니다.

## 이용 종료와 개인정보 요청

`/close`에서 종료 후 처리와 보관 사항을 읽고 확인값을 명시적으로 선택하면 본인 계좌 이용을 영구 종료하고 미체결 조건주문을 취소·예약 해제합니다. 종료 계좌는 복구·재개설할 수 없고 최초자금도 재지급되지 않습니다. 원래 Discord 사용자 ID·개설 확인 기록·원본 확인 nonce·개인 캐시·관심종목·가격 알림·DM 동의 설정·알림함·발송 상태·알림 중복 방지 키·내보내기 접근 기록은 제거·무효화합니다. 금융원장·조건주문/예약 전표·성과·기준전략·내부 계좌 ID·서버 범위 HMAC 연결값은 무결성과 재지급 방지를 위해 시장 존속기간 동안 가명 기록으로 보관합니다. HMAC을 익명정보로 보거나 이 절차를 모든 기록의 전체 삭제로 설명하지 않습니다. SQLite 이전 페이지·WAL·백업과 이미 전달된 Discord 첨부·DM의 파기는 별도입니다.

본인 조회와 내보내기는 위 명령으로 시작할 수 있습니다. 정정·전체 삭제·처리정지·기타 권리 요청은 `/privacy`에 표시한 실제 접수처로 요청합니다. 운영자는 본인 확인과 처리 결과·제한 사유를 안내해야 합니다. 현재 종료 확인은 인증된 Discord 명령과 본인 계좌 확인에 의존하며 별도 Discord 재로그인을 강제하지 않습니다.

## 운영과 문서 변경

개발 중 시스템 점검·오류·Discord 장애로 이용이 중단될 수 있습니다. 운영자는 오류를 조사하고 처리 결과를 안내합니다. 무료 시험이라는 이유로 관련 법령에 따른 책임을 일괄 배제하지 않습니다. 이용 제한이나 오류·계산 결과에 이의가 있으면 지원 접수처로 설명을 요청할 수 있습니다.

단계 6에서 운영 서버의 암호화 백업·무결성 검사·새 파일 복구를 추가합니다. 기본 정책은 1시간 백업, 최근 24개·7일별·4주별 대표 사본의 합집합 보관, 운영자가 별도 절대 경로를 설정한 경우 일별 복제, 30일 복구 리허설입니다. 실제 다른 물리 장치 복제나 장애 없는 전달을 보장하지 않습니다. 저장장치 유실 시 마지막 성공 사본 이후 기록은 복구할 수 없을 수 있으며 복구 목표·검증 범위는 [운영 절차](../OPERATIONS.md)에 따릅니다.
