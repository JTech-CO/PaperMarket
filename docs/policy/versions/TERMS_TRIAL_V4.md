# PaperMarket 시험 이용약관 초안

버전: `terms-trial-v4` / 작성일: 2026-10-04. 운영 주체와 실제 적용일은 공개 전 확정합니다. 실행 중 `/help`는 실제 운영 주체·지원 연락처를 표시합니다. [이전 v3](versions/TERMS_TRIAL_V3.md)와 v2·v1 원본을 보관합니다. 이 문서는 법률 자문이 아닌 개발용 초안이며 실제 공개 전 운영 사실과 전문가 검토가 필요합니다.

## 서비스와 시험 범위

PaperMarket은 가상 기업의 자산으로 투자 판단을 세우고 결과를 추적하는 모의투자 시뮬레이터입니다. 기업·현금·주식·거래는 모두 가상입니다. 실제 금융계좌·결제·환전·상품 판매·현금 보상은 제공하지 않습니다. 가상자금·계좌를 구매하거나 판매·양도할 수 없습니다. 다른 참가자가 없어도 본인 계좌를 개설하고 시스템에 시장가 매수·매도를 요청할 수 있습니다.

단계 4는 기업 회계·부채·가상 금리·공개 전망·사건 콘텐츠와 배당·부실·청산을 진행합니다. 사건은 실제 뉴스가 아닌 가상 기업의 시나리오입니다. 공개 시차·실제/예상/이전 값·불확실성을 구분하고 미공개 결과를 공개 시세 근거로 사용하지 않습니다. 사용자 수·주문량은 가격 경로를 바꾸지 않으며 전망은 확정 결과가 아닙니다. 현금 이자는 가상 연 252틱의 이율과 구간별 활성 보유시간으로 계산해 틱말에 지급합니다. 시험 결과는 실제 투자 수익을 예측하거나 보장하지 않습니다.

배당은 선언 T, 권리 확정 T+3, 지급 예정 T+5의 경제 틱을 기준으로 처리합니다. 권리 확정 직전 보유 수량으로 결정되고 이후 매도해도 유지되며 늦게 매수하면 해당 권리를 얻지 못합니다. 명목 금액·현재 평가·실제 지급은 다르고 기업 손상·청산으로 지급이 줄거나 0이 될 수 있습니다. 배당락과 권리 분리·현금 지급은 순자산에 중복 합산하지 않습니다.

청산 종목은 거래를 중단하고 기존 수량·취득원가를 회수권으로 이전합니다. 비용과 채권자 우선순위 뒤 남은 재산으로 최종 회수하며 손실은 그대로 남습니다. 같은 슬롯에 새 회사가 상장돼도 다른 발행사·종목이므로 새 주식이나 보상 현금을 자동으로 지급하지 않습니다.

## 계좌 개설과 이용

만 14세 이상 이용자가 개설할 수 있습니다. 이용자는 `/help`와 `/privacy`를 확인하고 `/open`에서 만 14세 이상과 이용약관 동의를 각각 명시적으로 선택합니다. 기본적으로 선택되었다고 간주하지 않으며 생년월일을 받지 않습니다. 연령은 이용자의 자기 확인이며 신분 검증은 제공하지 않습니다. 개인정보 처리 목적과 저장 사항은 별도의 개인정보 처리 안내에서 설명합니다.

계좌는 시장과 Discord 사용자에 연결됩니다. 최초자금 10,000은 시장별 한 번만 지급됩니다. 이름 변경, 서버 탈퇴 후 재가입, 봇 재초대, 계좌 종료로 재지급되지 않습니다. Discord 계정·접근 권한은 안전하게 관리해야 하며 타인 계정·주문을 사용하거나 소유자 확인·명령 제한을 우회하면 안 됩니다.

## 주문과 결과 확인

시장가 주문의 수량 또는 예산을 입력하면 시스템이 시세·수량·거래대금·수수료·체결 후 현금·유효기간을 표시합니다. 이용자가 확인 버튼을 누르고 소유자·유효기간·확정 시세 버전·자산 조건을 충족하면 전량 체결합니다. 확인 전 요청·취소·만료·거절은 체결이 아닙니다. 같은 확인을 다시 누르면 기존 결과를 제공하여 이중 체결을 막습니다.

지정가 매수·매도와 스톱 매도는 수량·조건가격·유효기간을 입력합니다. 스톱은 매도만 지원하며 지정가·스톱에 예산·전량 옵션을 함께 사용하지 않습니다. 확인 토큰은 최대 30초이고 견적 단계에는 자산을 예약하지 않습니다. 확인 시 이미 조건을 충족하면 현재 확정가로 체결하고 그 외에는 새 확정 시세마다 평가합니다. 지정가 매수는 현재가가 조건가격 이하, 지정가 매도는 이상, 스톱 매도는 이하일 때 실제 현재가로 전량 체결합니다. 스톱은 950에서 800으로 갭 하락해 900 조건을 통과했다면 800에 체결될 수 있으며 손실액을 보장하지 않습니다.

지정가 매수는 수량×조건가격과 최대 수수료에 해당하는 현금을, 매도·스톱은 주식 수량을 예약합니다. 예약 현금은 총 현금에 포함되고 예치이자를 얻으며 예약 주식도 배당 권리를 유지합니다. 중복 예약을 허용하지 않습니다. 기본 유효기간은 전체 시장 21틱이고 1~10,000틱 또는 취소할 때까지를 선택합니다. 정확히 만료 틱에서는 체결하지 않으며 같은 계좌의 여러 조건주문은 접수 순번으로 평가합니다. 경계에서는 만료→기업행동 취소→새 시세→조건 평가 순서로 처리합니다. 배당락·교환·소멸 때 해당 종목의 미체결 주문은 취소하고 새 종목으로 자동 이전하지 않습니다. 단순 배당 지급일은 취소 사유가 아닙니다.

본인 모의자산·가용/예약 자산·배당 및 청산 권리는 `/portfolio`, 최근 체결은 `/history`, 조건주문과 취소는 `/orders`에서 비공개로 확인합니다. 공개 지표·기업행동·사건 공시는 `/economy`, 공개 실적·배당 일정은 `/financial`에서 확인합니다. 공개 현황판에는 개인 거래를 표시하지 않습니다. 시세·계좌가 바뀌어 견적이 무효화되면 새 견적과 명시적인 재확인이 필요합니다. 차트·성과·지속 기준전략 보고서는 후속 단계입니다.

## 이용 종료와 개인정보 요청

`/close`에서 종료 후 처리와 보관 사항을 읽고 확인값을 명시적으로 선택하면 본인 계좌 이용을 영구 종료하고 미체결 조건주문을 취소·예약 해제합니다. 종료 계좌는 복구·재개설할 수 없고 최초자금도 재지급되지 않습니다. 원래 Discord 사용자 ID·개설 확인 기록·원본 확인 nonce·개인 캐시는 제거·무효화합니다. 금융원장·조건주문/예약 전표·내부 계좌 ID·서버 범위 HMAC 연결값은 무결성과 재지급 방지를 위해 시장 존속기간 동안 가명 기록으로 보관합니다. HMAC을 익명정보로 보거나 이 절차를 모든 기록의 전체 삭제로 설명하지 않습니다.

열람·정정·삭제·처리정지·내보내기는 `/privacy`에 표시한 실제 접수처로 요청할 수 있습니다. 운영자는 본인 확인과 처리 결과·제한 사유를 안내해야 합니다. 현재 종료 확인은 인증된 Discord 명령과 본인 계좌 확인에 의존하며 별도 Discord 재로그인을 강제하지 않습니다.

## 운영과 문서 변경

개발 중 시스템 점검·오류·Discord 장애로 이용이 중단될 수 있습니다. 운영자는 오류를 조사하고 처리 결과를 안내합니다. 무료 시험이라는 이유로 관련 법령에 따른 책임을 일괄 배제하지 않습니다. 이용 제한이나 오류·계산 결과에 이의가 있으면 지원 접수처로 설명을 요청할 수 있습니다.

중요한 약관·처리 범위 변경은 적용 전에 공지하고 이전 버전을 보관합니다. 새로운 수집·이용 또는 외부 전송을 추가할 때 필요한 별도 고지·동의를 검토합니다. 서비스 변경과 시험 종료 기준·일정은 실제 운영 전에 확정하여 알려야 합니다.
