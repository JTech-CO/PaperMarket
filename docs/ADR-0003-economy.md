# ADR-0003: 기업 경제·공개 정보·가격·현금 이자

상태: 단계 2 구현. 기준: 백서 5~8절·12.5절·13절·20절. 기록일: 2026-10-04.

## 버전과 기존 시장

경제 스냅샷 전체 버전은 `0.2.0`, 거시·기업 난수 문맥은 `economy-v1`, 공개 가치·가격 엔진은 `public-fcff-v1`이다. 기존 금융원장의 기반 버전 `0.0.0`은 유지한다. 서로 다른 책임의 버전을 섞어서 과거 전표를 재해석하지 않는다. 마이그레이션 1·2는 그대로 두고 3에 경제 상태·기업 전표·공시·가격 기여·금리 구간·계좌 이자·지급 기록을 추가한다.

새 시장의 경제는 0틱부터 진행한다. 기존 시장은 원래 시장 틱·가격·계좌·취득원가를 유지하고 저장된 `epoch_tick`을 경제 0틱으로 삼는다. 공시 일정·분기는 경제 틱 기준이다. 과거 오프라인 기간의 경제 틱·이자를 생성하지 않는다.

`MARKET_SEED`는 환경변수에만 두는 32~64바이트 난수이다. DB에는 원문 대신 시장별 검증 HMAC을 보관하고 다른 시드나 누락된 시드로 경제 DB를 열면 거절한다. 난수는 시장·버전·틱·기업·채널·draw index로 분리한다. 계좌 개설·조회·사용자 체결·응답 전송은 경제 난수를 소비하지 않는다.

## 회계와 기업 운영

기초 현금·운전자본·설비·무형자산·부채 계약은 단계 0 분해를 사용한다. 각 기업은 자산=부채+자본을 검증하고 모든 거래에 동일 금액의 차변·대변을 기록한다. 매출은 가격×판매량에서 출발하고 판매량은 수요·생산능력·생산성·고객 기반의 제한을 받는다. 재료·에너지·인건비·서비스·연구개발·감가·이자를 분리한다. 매출은 외상채권을 거쳐 수금되며 구매는 채무를 거쳐 지급된다.

내부 계약은 같은 원인의 공급자 매출/채권과 고객 비용 또는 건설중자산/채무를 연결한다. 내부 금액은 외부 매출·구매에서 제외하며 계약 공시는 현금흐름을 다시 기록하지 않는다. 공급 능력을 초과하는 수요를 내부 매출로 만들지 않는다. 연구개발은 당기 비용이다. 유동성 여력이 있는 설비투자는 계획 후 지출하고 6틱 뒤 완공하며 다음 틱부터 생산성·감가에 반영한다. 설비 내용연수는 2,520틱, 생산성 개선은 프로젝트당 0.005, 누적 상한 1.4로 둔다. 감가는 누적 목표 차액으로 계산해 마지막 원자까지 배분한다.

고정/변동 계약과 8개 만기군은 유지한다. 기업 이자는 매틱 비용·미지급이자로 발생하고 계약 지급일에 현금과 상계한다. 변동 계약은 21틱 재설정 시점부터 정책금리+스프레드를 적용한다. 만기 원금과 미지급 채무는 현금 범위에서 지급하며 부족액을 자동으로 지우거나 현금을 만들지 않는다. 채무 지연은 스트레스로 남기고 장기 연체 외상채권은 손상 처리한다. 본격적인 부실·청산 상태 전이는 단계 3이다.

분기 세전이익이 양수면 20% 법인세를 발생시키고 다음 틱에 지급한다. 손실의 현금 환급은 없다. 63틱마다 실적·현금흐름을 봉인하고 공개 후에는 수정하지 않는다. 합성 과거 실적은 실제 진행 결과와 별도로 표시하며 초기 감가·영업현금흐름 분해를 동일 helper로 공유한다.

## 거시 상태와 공개 경계

초기 정책금리 3%, 물가 2%, 산출갭 0, 수요·원자재·에너지·환율 지수 100, 신용 스트레스 0.2, 위험선호 0을 사용한다. 경기 국면은 최소 21틱 지속하고 국면에 맞는 목표를 향해 평균회귀한다. 산업수요·원자재 반감기는 63틱, 소비수요·물가는 84, 신용·에너지는 42, 환율은 126, 위험선호는 12틱이다. 충격은 별도 문맥의 12개 균등 난수 합으로 구성한 평균 0·분산 1의 유계 혁신이다.

정책회의는 21틱마다 열리며 기본 조정은 0 또는 ±0.25%p, 금리 범위는 0~15%다. 큰 긴급조정·사건 원인은 단계 4에 둔다. 공개 지표는 21틱마다 발표하고 물가·산출갭·수요·신용·위험선호에 독립 관측 오차를 더한다. 발표된 정책금리는 실제 결정과 같다. 공개 국면은 관측 지표에서 추정하며 내부 국면을 복사하지 않는다. 관측 오차를 기업 내부의 실제 거시 상태에 되먹이지 않는다. 다음 정책회의 확률은 마지막 공개 관측에서 산출한다. 관측 오차 혁신 계수는 물가 0.0015, 산출갭 0.003, 산업/소비 수요 0.35/0.25, 신용 0.01, 위험선호 0.02다.

기업 실적 발표 시차는 HGI/DNL +1, TLR/RVI +2, NXC/VTR +3, AUR/LMB +4틱이다. 공개 스키마는 미공개 필드·예정 실적·미래 날짜를 거절한다. 가격 엔진에는 이 공개 스키마만 전달한다. 발표 전 기대 매출과 실제 발표의 차이는 다음 공개 매출 성장·마진·성공/자금조달 실패 확률 추정에 반영한다.

## 가치평가와 가격의 구현 가정

20분기 명목 FCFF를 `영업이익 - 무차입 기준 세금 + 감가 - CAPEX - 운전자본 증가`로 계산한다. 이자는 FCFF에서 차감하지 않고 명목 연 WACC를 `(1+WACC)^(q/4)`로 할인한다. 성공·기본/실패·조달 실패 시나리오의 확률합은 1이다. 조달 실패·실패의 잔여 가치는 설비 회수, 영업 지속의 잔여 가치는 말기 FCFF 배수로 계산하는 대안이며 두 값을 더하지 않는다. 무한 고성장 영구모형은 쓰지 않는다. 영업가치에 공개 현금을 더하고 공개 부채와 다른 선순위 청구권을 한 번 차감한 뒤 주식 수로 나눈다.

백서에서 수치가 고정되지 않은 초기 튜닝 가정은 다음과 같다. 이는 실제 기업 가치·금융기관 예측을 주장하는 수치가 아니다.

| 항목 | 단계 2 가정 |
|---|---|
| 가치 변화 로그 계수 α | 0.08 |
| 공동 시장 잔차 σ | 0.003 |
| 장기 성장으로의 분기 fade | 0.9 |
| 집단 가중치 지속/목표 | 0.97 / 0.03 |
| 개별 집단 정서 지속/목표 | 0.85 / 0.15 |
| 초기 가치/성장/배당/추세/위험회피 가중치 | 0.25 / 0.20 / 0.15 / 0.20 / 0.20 |
| 명목 WACC 범위 | 2.5~45% |
| 장기 명목 성장 상한 | 4% |
| 공개 예상 정책금리 혼합 | 현재 금리 0.4 / 다음 회의 기대 금리 0.6 |
| 영업 잔여 가치 | 말기 연 FCFF × 일반 7배 / 성장·테마 8배 |
| 실패 설비 회수율 | 일반 실패 35% / 조달 실패 20% |

종목별 σ·β·κ는 백서 기본값을 그대로 사용한다. 가격은 가치 괴리·공개 가치 변화·공동 잔차·집단 정서 변화·종목 잔차를 합한 로그 수익률의 지수로 갱신한다. 일반 조정은 ±30%로 제한하며 700→490 및 극소 양수 가격을 보존한다. 할인율 변화 외에 정책금리 충격을 주가에 중복 차감하지 않는다. 기본 가치 0은 양수 거래가격을 즉시 0으로 바꾸는 신호가 아니다. 가격 기여에는 제한 조정·정밀도 반올림도 기록해 실제 변화와 합을 맞춘다. 추정 기본 가치는 사용자에게 정답 가격으로 표시하지 않는다.

## 예치금 이자와 커밋

현금 연이율은 `max(정책금리-0.005,0)`, 일 실효이율은 `(1+연이율)^(1/252)-1`이다. 틱 시작 금리로 활성 300,000ms 동안의 각 현금 보유 구간을 정확한 분수로 합산한다. 매수·매도 전에 이전 현금 구간을 마감하고 새 현금으로 다음 구간을 연다. 예약 현금은 포함하며 주식·미지급 권리·오프라인 시간은 포함하지 않는다. 틱 내부 복리는 없고 지급된 이자는 다음 틱부터 원금이 된다. 발생 이자와 원자 미만 carry를 중복 없이 합쳐 원자 금액으로 내림 지급하고 나머지를 이월한다.

틱 하나의 기업 전표·경제/공개/가격 스냅샷·공시·시세·금리 구간·사용자 이자·원장·버전은 같은 즉시 트랜잭션으로 커밋한다. 실패 시 전체 롤백 후 시장을 정지한다. 스냅샷과 이자 상태의 정규 직렬화·해시를 검증하며 재시작은 저장된 상태를 이어 간다. 지급은 계좌·틱 고유키로 중복을 막고 실제 지급 시 계좌 버전을 올린다. 틱 내 이자 발생만으로 견적 버전을 바꾸지 않는다.

정지 시각의 남은 활성시간을 별도 트랜잭션으로 보존한다. 정지 중 조회·재시작이 이자를 더 발생시키지 않으며 금융 틱 실패는 상수 진단 코드로 기록한다. 공개 현황판은 마지막 성공 스냅샷으로 남을 수 있다. 자동 장애 공지·복구 알림은 단계 6 운영 범위이고 현재 상태는 `/status`로 확인한다.

## 조회와 검증

`/market`은 가격·등락·공개 금리, `/economy`는 발표 지표·회의 기대·최근 공시, `/financial`은 공개된 최근 분기와 연 전망을 표시한다. 개인 조회·버튼은 비공개이고 본인 계좌 조건을 유지한다. 이자 발생액은 포트폴리오 총자산에 한 번 포함한다. 정책 초안 v2는 이 계산과 개인정보 흐름을 반영하고 v1 문서를 보관한다.

합성 데이터 검사에는 실제 SQLite 원자 커밋·롤백·오프라인 복구·잘못된 시드 거절·가격/이자 손상 검출·두 시장 경로 대조·504틱 기업 회계 검증을 포함한다. 실제 Discord 연결·공개 운영·부하·장기 모형 보정은 수행하지 않았다. 독립 진단은 `npm run verify:economy`로 실행한다.
