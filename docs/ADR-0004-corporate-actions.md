# ADR-0004: 배당 권리·부실·청산과 회사 세대

상태: 채택 / 날짜: 2026-10-04 / 범위: 단계 3

## 결정

경제 스냅샷 버전은 `0.3.0`이며 기업행동은 참가자 계좌·보유량·명령과 독립적으로 계산합니다. 기업의 경제적 발행주식 수와 플레이어 측 모의 수량은 별도 장부입니다. 사용자 100명의 보유 수량이 기업 지급액을 100배로 만들지 않습니다. 공개 기업행동만 계좌 권리와 가격 모듈에 전달합니다.

단계 2 스냅샷은 원래 JSON·해시·버전을 검증한 후 메모리에서 기본값을 추가합니다. 첫 신규 틱부터 새 버전으로 기록하며 과거 스냅샷·현금·수량·취득원가·가격을 다시 쓰지 않습니다. 마이그레이션 4는 기업행동·권리 원장·기업행동에 따른 주문 취소 사유를 추가하고 기존 1~3을 유지합니다. 기업·공개·가격·DB의 발행사/상장/슬롯/세대 식별자는 교차 검증합니다.

## 배당 정책과 기업 회계

배당 후보는 마지막 4분기의 정상화 분기 이익에서 일회성 손익을 제거하고 모형 세율 20%를 적용합니다. 초기 기업의 목표 배당성향을 곱한 이익 한도, 미예약 현금에서 안전 잔액을 뺀 한도, 양의 누적이익 한도 중 최소를 선택합니다. 성장·테마 기업은 초기 배당 0입니다. 연체·배당 금지·부실 상태는 신규 선언을 막습니다.

안전 잔액은 마지막 공개 전 봉인 분기의 비현금 감가·차입 이자를 제외한 21틱 영업비용, 21틱 내 원금·발생 및 예정 이자·세금·약정 CAPEX, 영업비용의 1/3 완충액입니다. 매입채무를 같은 영업비용에 다시 더하지 않습니다. 배당 예약 현금은 다른 기업 지급에 재사용하지 않습니다.

후보 계산은 내부 제안 단계이고, 양의 배당만 선언합니다. 선언 T에 누적이익 차변/배당채무 대변과 현금 예약을 기록합니다. T+3 권리를 분리하고 T+5 배당채무 차변/현금 대변으로 지급하며 비용이나 이익을 다시 발생시키지 않습니다. 지급 여력 손상은 명목 배당을 유지하면서 공개 회수율·채무·권리 평가에 반영합니다.

## 계좌 권리와 정밀 정산

배당락 경계 직전의 실제 보유 수량에 확정 기업 총액/발행주식 수를 곱해 정확한 분수의 권리를 만듭니다. 이후 매도해도 남고 이후 매수하면 얻지 못합니다. 오프라인 사용자는 동일하게 처리합니다. 계좌 종료 후 기존 보유·권리는 무결성 정산을 기록하지만 계좌 이용은 복구하지 않습니다.

권리 장부는 시장·계좌 범위의 추가형 상태 전표입니다. 각 전표에 이전 해시·현재 해시와 수량·명목·평가·지급·원가의 반대 부호인 시스템 대응 상태를 기록합니다. 재생은 소유 범위·연결 해시·대응값·현금 지급 원장 총액을 대조합니다. 기업행동 ID의 넓은 문법은 기반 금융 원장에서는 결정적 해시 원인 ID로 변환하며 원래 연결은 권리 전표에 유지합니다.

실제 현금 배분에는 Decimal로 반올림된 회수율·주당 회수액을 사용하지 않습니다. 배당은 기업 확정 지급 원자 총액/명목 원자 총액, 보통주 청산은 확정 보통주 지급 원자 총액/귀속 발행주식 수의 정확한 분수를 사용합니다. 지급은 원자 단위로 내림하고 같은 계좌·권리 종류의 원자 미만 잔액을 모아 이후 지급에 이월합니다. 잔액은 총자산에 포함되지만 현금 이자 원금이 아닙니다.

가격용 주당 값과 현재 평가는 50 유효자리 계산을 사용합니다. `/portfolio`는 명목·현재 평가·실제 지급과 청산 취득원가·최종 손익을 구분하며 최근 5건을 표시합니다. 전체 현재 권리 평가와 잔액은 총자산에 한 번 포함됩니다. 지급된 권리는 평가 0으로 남고 지급 현금만 자산에 포함됩니다.

## 배당락과 0 참조값

전체 주가를 계속기업 부분과 부착 배당의 현재 가치로 나눕니다. 선언은 기존 전체 가치 안에서 재분류하고 배당락은 동일 틱·회수율·할인율의 부착 권리를 별도 채권으로 분리합니다. 이후 일반 가격 변동 ±30%는 계속기업 부분에 적용합니다. 지급일에 다시 배당락하지 않습니다.

전체 시세가 권리의 현재 가치보다 작거나 계속기업 부분이 정확히 0인데 공개 모형의 계속기업 가치가 양수라면 기업행동 버전에서 공개 모형 값으로 조정하고 조정 기여를 별도 기록합니다. 고정 최저가격을 두지 않습니다. 순수 권리 변환은 권리만 존재하는 상태와 최종 0을 반환할 수 있고 로그 가격 커널을 실행하지 않습니다. 활성 상장에 전체 0이 남으면 저장 전에 `ZERO_CORPORATE_REFERENCE`로 틱을 롤백하고 시장을 중단합니다. 모형·버전 문제를 해결하기 전 무료 주문이나 가격만 보고 임의 청산을 만들지 않습니다.

## 부실·증자·청산 모형

상태는 영업→주의→부실→재구조화→청산→최종 소멸이며 가격 하락 자체는 부실 입력이 아닙니다. 미예약 현금의 영업 지속 기간·21틱 의무·연체 기간·자산 대비 채무 위반을 계산합니다. 부실이 21틱 지속되고 회사가 63틱 이상 존재하면 외부 자본 조달을 시도합니다.

조달은 최대 2회이고 필요액은 초기 현금의 2배 이내입니다. 성공 확률은 `max(0.05, 0.9 - 신용위험×0.5 - 재무위반×0.25)`이며 독립 기업 난수 문맥을 사용합니다. 발행 단가 250으로 정수 신주를 계산하고 현금·납입자본·총주식 수를 함께 늘립니다. 기존 사용자 수량은 늘리지 않습니다. 이 값들은 현실의 회생·금융 법규가 아닌 가상 경제 보정 가정입니다.

조달 실패 시 영업을 멈추고 5틱 뒤 청산 정산을 진행합니다. 현금 100%, 매출채권 60%, 재고 50%, 운영자산 35%, 무형자산 10%, 건설중자산 20%의 회수와 3% 청산 비용을 가정합니다. 부채의 60%를 담보, 나머지 40%를 후순위로 분류합니다. 비용→담보→매입채무·이자·세금 선순위→후순위 부채와 배당→보통주 순서입니다. 같은 순위의 부족액은 정수 원자 비례 배분과 최대 나머지 배분으로 정산해 0 청구에 지급하거나 청구액을 넘지 않습니다.

청산 진입 당시 미배당락 선언도 기존 수량에 부착 권리로 보존합니다. 옛 회사의 T+3 배당락은 예정대로 확정하고 T+5 통상 지급은 청산 우선순위 정산까지 보류합니다. 회사 배당채무는 추정 회수율만으로 미리 감액해 순위 분모를 바꾸지 않으며 최종 실제 지급·손상으로 해소합니다. 보통주 회수와 배당 회수는 분리하여 중복 지급하지 않습니다. 옛 공급업체 채권의 현금 회수도 원래 상대 발행사에 귀속합니다.

## 종목 대체와 검증 경계

청산 진입과 같은 경계에서 같은 범주의 새 회사를 1,000에 편입합니다. 영구 발행사/상장 ID·세대 심볼·기초 회계·합성 초기 실적·가격 난수 문맥이 독립적입니다. 옛 발행사는 퇴역 상태로 보관하여 공급업체 계약·권리·최종 0을 유지합니다. 기업 신규 기초 잔액도 `REPLACEMENT_OPENING` 전표로 재생합니다. 기존 수량을 신주로 바꾸거나 손실을 초기화하지 않습니다.

배당락·청산은 해당 종목의 미확정 견적을 취소하고 본인 확인 요청에 원인을 반환합니다. 기업·공시·가격·이자·권리·현금·수량·주문 취소·상장 교체를 동일 SQLite 트랜잭션에서 커밋합니다. 늦은 권리 전표 실패도 모두 롤백합니다. 실제 Discord 전송은 이후 별도로 진행합니다.

PM8 기준전략은 기존 청산 원가·회수·손실을 남기고 자기 현금과 수수료로만 새 주식을 사는 순수 계산 계약을 검사했습니다. 지속 기준계좌·차트·성과 보고 UX는 단계 5입니다. 사건 콘텐츠·조건 주문은 단계 4, 부하·장기 모형 보정·운영 개인정보·백업 복구 검증은 단계 6입니다.
